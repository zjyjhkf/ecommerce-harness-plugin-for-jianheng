# 广告流量（Ad Traffic）

分析流量结构与广告投放效率，定位浪费点并给出优化方案。

## 何时使用

- 广告诊断 / 降 ACOS / 预算分配 / 流量来源分析

## 分析框架

1. **流量结构盘点**
   - 自然流量 vs 广告流量的占比与趋势；流量入口（搜索词 / 商品页 / 榜单 / 站外）。
   - 判断是「流量不足」还是「流量不精准」。
2. **广告效率指标**
   - ACOS、CPC、CTR、CVR、广告花费占比；按「广告目标（曝光/转化/盈利）」区分评价标准。
   - 拆到「广告组 → 投放词 → 搜索词」三层，找高花费低转化的浪费词。
3. **结构诊断**
   - 广告类型（SP/SB/SD）、自动 vs 手动、广泛/词组/精准的匹配结构是否合理。
   - 自动广告跑出的优质搜索词是否「提权」到手动精准；无效词是否及时否定。
4. **竞价与预算**
   - 对比 CPC 与客单价/毛利，判断竞价空间；预算是否集中在高转化时段/词。
5. **优化动作**
   - 提权优质词、否定无效词、调竞价、重分配预算、优化广告素材与落地（关联 listing 承接）。

## 数据来源

- 广告后台报表（campaign/搜索词/ACOS/CPC/预算）；流量来源（OpenBoost `amz_traffic_source` / `amz_traffic_keyword`）。
- 店铺侧：`stats_*` 的客单价/转化，用于衡量广告投入产出。

## 输出格式

1. **效率结论**：ACOS/CPC/CVR 是否健康 + 一句话诊断。
2. **浪费点定位**：高花费低转化词/广告组清单。
3. **优化清单**：竞价/预算/否定词/结构调整，按 P0/P1/P2。
