# 关键词研究（Keyword Research）

挖出用户真实搜索词，评估价值，产出 Listing 埋词与广告投放的关键词方案。

## 何时使用

- 挖词 / 选词 / 关键词布局
- 用户问「用户搜什么词」「哪些词值得投」

## 分析框架

1. **种子词挖掘**
   - 从产品核心功能、使用场景、同义词、竞品标题/评论高频词中提取种子词。
2. **长尾词扩展**
   - 用关键词工具/联想词/ABA 反向查找，扩展出长尾与场景词（例：`for women`、`wireless`、`gift for`）。
3. **评估与分级**
   - 每个词看：搜索量（需求）、竞争度（PPC 竞价/首页垄断）、相关性（是否精准）。
   - 分级：大词（引流）/ 精准词（转化）/ 长尾词（低竞争切入）。
4. **词与场景对齐**
   - 流量词 → 投广告引流；转化词 → 埋入标题与五点；长尾词 → 新品冷启动切入。
5. **产出词表**
   - 给「Listing 埋词方案」与「广告词分组（精准/广泛/否定词）」两套。

## 数据来源

- **店铺侧（本插件，主）**：自身商品的 `name` / `category`（`product_list`）、`stats_top_products`（畅销商品）作为种子词来源。
- **外部（可选，若已接入）**：种子词挖掘 / 选词 / 趋势 / 流量结构 / ABA（OpenBoost `amz_keyword_miner` / `amz_keyword_research` / `amz_traffic_keyword` / `amz_aba_*`）。未接入时基于店铺商品与类目做种子词与长尾扩展，并标注「搜索量/竞争度数据缺失」。

## 输出格式

1. **词表**：关键词、搜索量、竞争度、相关性、建议用途（埋词/广告/否定）。
2. **Listing 埋词建议**：标题主词 + 五点/描述长尾词 + SearchTerm。
3. **广告分组建议**：精准/广泛/词组 + 否定词。
