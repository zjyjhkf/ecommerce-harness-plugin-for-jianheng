# 市场机会（Market Opportunity）

判断一个类目 / 细分市场是否值得进入、以什么切入点进入。

## 何时使用

- 选品 / 选市场 / 选类目
- 用户问「这个市场大不大、好不好做、还能不能进」

## 分析框架

1. **市场容量与趋势**
   - 类目/关键词的搜索量、销量规模、近 6–12 个月趋势（上升/平稳/下滑）。
   - 用趋势判断是「红利期 / 成熟期 / 衰退期」。
2. **价格带分布**
   - 主流成交价区间、各价格带销量占比；判断利润空间与定位空间（低价冲量 vs 高价做差异）。
3. **竞争格局**
   - 头部品牌 / 卖家的市占率、评论数与评分分布；判断「垄断 / 分散 / 有缝隙」。
   - 新品存活率、首页（Top 20）被老品占据的程度。
4. **进入门槛与风险**
   - 资金（备货）、认证/合规、专利侵权、季节性、物流/退货成本。
5. **机会点判定**
   - 找「高需求 × 低竞争 × 有差异化空间」的细分：未被满足的场景、人群、价格带、功能点。

## 数据来源

- **店铺侧（本插件，主）**：`stats_overview` / 类目分布 / 近 30 天趋势（`stats_trend`）、`product_*`（价格带）、`inventory_*`（备货）——反映自身所在市场的表现。
- **外部（可选，若已接入）**：类目树、市场容量/统计、价格带、品牌/卖家结构（OpenBoost `amz_market_*` / `amz_category_query_v2` 等）、TikTok Shop 品类大盘。未接入时基于店铺侧类目/价格带数据做判断，并标注「市场容量/集中度数据缺失」。

## 输出格式

1. **市场判断**：进入 / 谨慎 / 放弃 + 一句话理由。
2. **关键数字**：容量、趋势、主流价格带、头部集中度、进入门槛。
3. **推荐切入点**：目标价格带 + 差异化方向（1-3 个候选）。
4. **风险与下一步**：需验证的假设，及建议调用的专项技能。
