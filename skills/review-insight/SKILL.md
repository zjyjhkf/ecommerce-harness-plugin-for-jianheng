# 评论洞察（Review Insight）

从用户评论中挖掘真实卖点、痛点与改进机会。

## 何时使用

- 分析某个商品 / 竞品 / 类目的评论
- 用户问「用户喜欢什么、抱怨什么、怎么改进」

## 分析框架

1. **采集与清洗**
   - 拉取目标商品/竞品的评论（含评分、标题、正文、图片、是否已购、时间）。
   - 过滤水军/无效评论，按 1-2 星（差评）、3 星（中性）、4-5 星（好评）分层。
2. **好评卖点提取**
   - 高频正面词/句 → 归纳用户真正认可的点（质量、性价比、外观、易用、物流）。
   - 这些卖点应体现在 Listing 图片与五点里。
3. **差评痛点归纳**
   - 高频负面点 → 按「产品缺陷 / 描述不符 / 物流售后 / 预期落差」归类。
   - 判断哪些是「可修复的产品问题」、哪些是「需在 Listing 前置说明以降低预期」。
4. **场景与人群洞察**
   - 从评论里发现使用场景、购买动机、人群特征，反哺选品与关键词。
5. **行动转化**
   - 每个 Top 痛点/卖点 → 对应一条改进动作（改产品 / 改 Listing / 改售后 / 改广告文案）。

## 数据来源

- 商品/ASIN 评论接口（OpenBoost 评论能力或平台后台 Review 导出）。
- 店铺侧：`stats_*` 的退款率 / `order_*` 的退款原因，作为售后痛点的旁证。

## 输出格式

1. **好评卖点 Top 5**：卖点 + 佐证评论数 + 建议用途。
2. **差评痛点 Top 5**：痛点 + 出现频率 + 根因 + 改进动作。
3. **场景/人群洞察**：1-3 条。
4. **行动清单**：按 P0/P1/P2。
