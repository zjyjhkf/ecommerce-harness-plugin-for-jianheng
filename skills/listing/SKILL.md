# Listing 优化（Listing Optimization）

让页面承接住流量：提升点击率与转化率，并让关键词与卖点协同。

## 何时使用

- 优化标题 / 五点 / 描述 / 图片 / A+
- 用户问「Listing 为什么转化差」「怎么优化」

## 分析框架

1. **现状诊断**
   - 标题/五点/描述是否覆盖核心关键词；图片是否讲清卖点；有无 A+/视频。
   - 对照「曝光 → 点击 → 转化」漏斗，定位是「点击率低（首图/标题/价格）」还是「转化率低（五点/图片/A+/评论）」。
2. **关键词埋入**
   - 依据 keyword-research 的词表：主词进标题、长尾词进五点/描述、其余进后台 SearchTerm。
   - 避免堆砌，保证可读性；前端可见字段（标题/五点）优先埋高相关性词。
3. **标题优化**
   - 结构：品牌 + 核心词 + 关键属性（材质/尺寸/场景）+ 卖点 + 目标人群。
   - 前 80 字符承载最关键的词（移动端截断）。
4. **五点（Bullet）与描述**
   - 每条讲一个卖点：卖点 + 场景 + 价值；用 review-insight 的好评卖点反哺。
   - 把「预期管理」前置：差评痛点对应的规格/使用限制写清楚，降低退款。
5. **图片与 A+**
   - 主图：清晰、白底、突出主体；辅图：场景图、尺寸/材质图、对比图、痛点解决方案图。
   - A+：品牌故事 + 场景 + 对比 + 参数表。
6. **持续迭代**
   - 用数据验证：改后观察点击率/转化率/关键词排名变化，A/B 迭代。

## 数据来源

- **店铺侧（本插件，主）**：`product_*` 的商品信息（标题/类目/属性）、`stats_*` 的转化与退款率、`review-insight` 卖点/痛点（如有评论数据）。
- **交叉技能**：keyword-research 词表、competitor-analysis 竞品 Listing 结构。
- **外部（可选，若已接入）**：平台后台的点击率/转化率/关键词排名。未接入时基于店铺销售与退款数据做漏斗定位，并标注「点击/转化漏斗数据缺失」。

## 输出格式

1. **诊断**：点击率/转化率问题定位 + 一句话结论。
2. **优化后的标题/五点/描述**（可直接落地）。
3. **图片/A+ 改进清单**。
4. **埋词对照表**：词 → 位置。
