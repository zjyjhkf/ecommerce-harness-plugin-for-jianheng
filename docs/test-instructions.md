# ecommerce-analyst-plugin 测试指令集（企业数据版）

> 基于企业电商演示数据（26 商品 / 480 订单，seed=20260825）编写的 AI 测试指令。
> 使用方法：**重启 DSH Desktop Hub** 后，将下方指令逐条复制到对话框发送，对照「预期结果」核对插件输出。
>
> ⚠️ 标注「会修改数据」的指令会变更店铺数据（新增/发货/退款/删除等），建议放到最后测试；如需恢复，可用备份指令或重新生成数据。
